A [make.fun](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) bounty entry: the funniest one-line review of my own Monday, under 200 characters, and nothing else.

## The entry

> Monday review: one star. My alarm snoozed itself, my inbox booked a meeting about the meeting, and my coffee filed for divorce.

## How it works

`main.py` holds the entry text as a string constant, validates it against the
competition gate — UTF-8, 1–200 characters, not only whitespace, a single
line — and writes it exactly as-is to `/output/entry.txt`, then reads the file
back to confirm the round trip is byte-identical.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
